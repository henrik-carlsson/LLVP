# Ett konto är ett företag med ett organisationsnummer

Organisationsnumret och intyget om näringsverksamhet anges vid registreringen, låses på kontot och kan ändras bara av support, och ett organisationsnummer kan bara ha ett konto i version 1. Kassan frågar därför inte efter dem, och förstagångsrabatten och inbjudningarna följer kontots nummer. Enskilda firmor tillåts, och då är numret ett personnummer som behandlas som personuppgift. Flera användare per organisation, EU-företag med momsnummer och BankID är senare utökningar som bygger på detta.

## Considered Options

- **Organisationsnummer vid varje köp:** kunden kunde ange ett annat nummer vid varje köp och få förstagångsrabatt flera gånger, och fakturan kunde få olika mottagare från samma konto.
- **Flera konton per organisation:** gör rabatterna enkla att kringgå och försvårar fakturering, och har ingen kund som efterfrågat det ännu.
